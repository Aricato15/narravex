# Capture or update topic knowledge

Read working/knowledge_folder/index.md and relevant topics. Update an existing topic or create one using template/forms/topic.md. Assign stable IDs (workflows/00-conventions.md), link evidence and keep proposals/questions separate from confirmed items. Cite sources as Source ID plus locator (e.g. `SRC-004 p.17`); the full file list is in working/SOURCES.md. Record explicit user decisions without repeated confirmation. Update index, revisions and slide usage. Mark affected slides stale (with a stale_reason) when content changes.

Content from new files arrives via the intake workflow (workflows/02-intake.md), which proposes knowledge changes and calls this workflow to apply the ones the user accepts.
