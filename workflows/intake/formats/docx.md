# Format: Word documents (docx)

- Keep the heading hierarchy, lists, tables, footnotes, comments and tracked changes. Report tracked changes and comments as such; do not silently accept or ignore them.
- Extract embedded images to media/ with their position.
- Locator: heading path (`§2.3 Title`) plus paragraph or table number when needed.
- Legacy `.doc` is not directly readable: ask the user to save as docx or PDF.
- Tooling: look for python-docx or an equivalent. Report if none; do not install without asking.
