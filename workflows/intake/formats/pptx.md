# Format: PowerPoint (pptx)

- Read per slide: title, text boxes in reading order, tables, speaker notes, grouped shapes, connectors with direction, alt text.
- Native charts: read the embedded chart data. These values are real data and may be recorded as such (method `native data`). Note the chart type and series names.
- Theme intent: also read the theme XML (colours, fonts) and slide layouts/masters, not just the rendered look.
- Locator: `slide N` plus shape name or table cell where useful.
- Pictures and SmartArt may not be fully readable; record what is visible and flag the rest.
- Tooling: look for python-pptx or an equivalent; a renderer (e.g. LibreOffice) helps for visual checks. Report if none; do not install without asking.
