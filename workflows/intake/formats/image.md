# Format: images (png, jpg, gif, webp, etc.)

- Read the image visually. Transcribe all visible text, labels, values and units exactly. Mark unreadable text as unreadable; never guess.
- Record layout: reading order, groups, hierarchy, connectors with arrow direction, legend, semantic colours.
- Charts shown only as images: describe the chart type and visible labels; mark data values as unavailable unless printed on the chart. Ask the user for the underlying data.
- Method: `vision`. Locator: the region (e.g. "top-left panel") or label.
- Tooling: none required to view. Large images may need description by region.
